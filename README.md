# 🚗 Vehicle Rental System – Java

A simple Java-based Vehicle Rental System developed to practice Object-Oriented Programming (OOP) concepts and Java type conversion techniques. This project demonstrates Inheritance, Method Overriding, Dynamic Method Dispatch, Upcasting, Downcasting, Wrapper Classes, Autoboxing, Auto-unboxing, and String-to-Integer conversion using real-world vehicle rental scenarios.

## ✨ Features

- 🚗 Create a parent `Vehicle` class with a `calculateRent()` method.
- 🏍️ Create `Car` and `Bike` subclasses using inheritance.
- 🔄 Override `calculateRent()` to return vehicle-specific rental amounts.
- ⬆️ Use upcasting to store `Car` and `Bike` objects in `Vehicle` references.
- 🎭 Demonstrate dynamic method dispatch through parent class references.
- 🔽 Access the `showCarType()` method using downcasting.
- 🔢 Convert rental amounts from `String` to `int` using `Integer.parseInt()`.
- 📦 Demonstrate autoboxing and auto-unboxing with `int` and `Integer`.
- 🔑 Use `Integer.valueOf()` and `intValue()` for explicit boxing and unboxing.
- 🏗️ Practice real-world OOP concepts through a vehicle rental management example.
